# Mi Primer Sitio Web (Despliegue de aplicaciones web y moviles)

Este es mi primer proyecto de despliegue web, creado desde cero para el despliegeue de aplicaciones

## Tecnologías utilizadas
* HTML5
* CSS3 (con animaciones)
* Git y GitHub para el control de versiones

## 📦 Proceso realizado hasta ahora
1. Creación de la estructura del proyecto (`/css`, `/img`, `/js`).
2. Optimización de imágenes y minificación de código CSS para mejorar la velocidad.
3. Empaquetado del proyecto.
4. Inicialización de repositorio local y subida a la nube.
